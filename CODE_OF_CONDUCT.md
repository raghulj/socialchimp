# Code of conduct

Be decent to people. That covers nearly all of it, but the specifics below
are worth writing down.

## What is expected

- **Assume the other person is trying.** Somebody asking a question that
  seems obvious has read something confusing, and that is usually our fault.
- **Be direct about code and kind about people.** "This drops the token on a
  refresh failure" is useful. "This is careless" is not, and says nothing the
  first sentence did not.
- **Say when you are unsure.** It is more useful than confidence that turns
  out to be wrong, and it makes it safe for everybody else to do the same.
- **Accept a decision once it is made**, including one that went against you.

## What is not acceptable

Harassment, insults, or personal attacks. Comments demeaning to somebody
because of who they are. Publishing anyone's private information.
Deliberately wasting people's time.

## If something goes wrong

Report it privately through
[GitHub's report abuse form](https://github.com/contact/report-abuse), or by
opening a private security advisory on this repository if you would rather
reach the maintainers directly.

Reports are taken seriously and handled discreetly. Responses range from a
quiet word to a permanent ban, depending on what happened. Whoever handles a
report stays out of it if they are involved themselves.

## Where this applies

Anywhere this project happens - issues, pull requests, discussions, and
anywhere somebody is representing the project.
